# `pbl swipe`

Swipe across the running emulator's screen, on touch-capable boards. The
finger moves from the first point to the second through intermediate steps,
so drag gestures are seen as continuous.

```shell
pbl swipe 130 220 130 40                              # swipe up
pbl swipe 130 220 130 40 --steps 20 --duration 0.4
```

## Options

```{pbl-command} swipe
```
