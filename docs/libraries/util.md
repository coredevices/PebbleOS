# Utilities

General purpose helpers: linked lists, circular buffers and caches, sorting,
fixed-point math and trigonometry, calendar time, strings and UTF-8, base64,
hashes, UUIDs, byte order and bit operations, and more. Each module has its
own header.

| | |
| --- | --- |
| Directory | `lib/util` |
| Header | `pbl/util/<module>.h` |
| Kconfig | Always built |
| API | {apidoc}`API reference <util>` |
