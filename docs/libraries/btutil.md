# Bluetooth utilities

Helpers for Bluetooth device addresses, UUIDs and the pairing information of
the security manager, shared by the {doc}`Bluetooth subsystem <../subsystems/bluetooth>`
and the code around it.

| | |
| --- | --- |
| Directory | `lib/btutil` |
| Header | `pbl/btutil/bt_device.h`, `pbl/btutil/bt_uuid.h`, `pbl/btutil/sm_util.h` |
| Kconfig | `CONFIG_BTUTIL`, selected by the Bluetooth subsystem |
| API | {apidoc}`API reference <btutil>` |
