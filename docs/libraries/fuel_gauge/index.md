# Fuel gauge

`lib/fuel_gauge/` estimates the state of charge (SOC) of a single Li-ion or
Li-po cell from periodic voltage, current and temperature measurements.

| --- | --- |
| Directory | `lib/fuel_gauge` |
| Header | `pbl/fuel_gauge/fuel_gauge.h` |
| Kconfig | `CONFIG_FUEL_GAUGE`, selected by the code that uses it |
