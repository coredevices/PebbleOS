# Playground

PebbleOS, running in your browser: the firmware of the `native_emery`
virtual watch, built as WebAssembly. Click the watch's buttons, or the
screen and then use the arrow keys (left is back, right is select); the
mouse is a finger on the screen.

```{pbl-playground}
```

Nothing is saved: the watch starts afresh every time the page loads. To run
the same build yourself, see
{doc}`development/emulation/native_simulator`.
