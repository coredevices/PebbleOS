# Crypto: SHA-256

This sample hashes the two example messages of FIPS 180-4 with
{doc}`SHA-256 <../../../subsystems/crypto>`, one of them two blocks long,
then a thousand bytes both in one call and fed in uneven chunks: the context
keeps a partial block until the next update completes it, so both digests
are the same.

Boards with a hash accelerator use it for long runs of blocks, and software
for the rest.
